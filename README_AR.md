# IP Port Scanner — Android

تطبيق Android بسيط بواجهة داكنة لفحص 12 منفذًا شائعًا على عنوان IPv4 واحد في كل مرة. مخصص للاستخدام على الأجهزة التي تملكها أو لديك تصريح بفحصها.

## المتطلبات
- Android Studio حديث
- JDK 17
- Android SDK Platform 35
- اتصال إنترنت لتنزيل مكونات Gradle عند أول بناء

## بناء APK
1. فك ضغط المشروع.
2. افتح Android Studio واختر Open ثم مجلد `IPPortScanner`.
3. انتظر مزامنة Gradle وتنزيل المكونات المطلوبة.
4. من القائمة اختر Build > Build APK(s).
5. بعد نجاح البناء سيظهر رابط Locate، والملف عادةً في:
   `app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات
- `open`: اتصال TCP نجح عند الفحص.
- `closed`: الجهاز رفض الاتصال.
- `لم يستجب / قد يكون محجوبًا`: انتهت المهلة؛ لا يمكن الجزم بأن المنفذ مغلق.
- لا توجد حاجة إلى روت.
- هذا المشروع مصدر قابل للبناء، وليس ملف APK جاهزًا.
